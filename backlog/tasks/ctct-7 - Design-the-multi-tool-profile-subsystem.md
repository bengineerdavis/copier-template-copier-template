## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
A profile is a named, versioned, template-side map of answers spanning several tools (alint, openspec, backlog, prek, license defaults). Prefer Copier's native mechanisms (defaults/data file, reusable answers) before building anything custom; only add a CLI or file format for what Copier cannot express. Multi-select profiles must compose (e.g. agentic + a language profile).
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A written comparison of what Copier defaults/data + answers reuse cover versus what a new profile format would add
- [ ] #2 A proposed profile file format and merge rule for multi-select, or a recorded decision to defer both
- [ ] #3 A decision on whether a profile CLI ships now or is deferred, with its audience and write model
